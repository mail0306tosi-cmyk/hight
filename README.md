# hight
Height sharing SNS

## HIGHT の標高測定

HTML・CSS・JavaScript だけで動くスマートフォン向け Web アプリです。

### ローカルで起動

```sh
cd /workspace/hight
python3 -m http.server 8000 --bind 127.0.0.1
```

開発用ブラウザーから localhost のポート 8000 で確認できます。スマートフォンで使う場合は HTTPS で配信してください。通常の HTTP の LAN アドレスでは位置情報 API を利用できません。

「標高を測定」を押し、位置情報を許可すると `navigator.geolocation.getCurrentPosition` の `coords.altitude` をメートル単位で表示します。0 m や負の高度も表示できます。標高が null の端末、権限拒否、測位失敗、20 秒のタイムアウトは日本語で案内します。測定中はボタンを無効にし、再測定時には以前の結果を消します。

アプリは緯度・経度を読み取らず、取得した位置情報を外部送信・永続保存しません。外部ライブラリーや外部 API も使用せず、CSP で JavaScript のネットワーク接続を禁止しています。ただし、端末・ブラウザー自体の位置特定方式は OS やブラウザーの仕様に依存します。高度は端末の報告する海抜高度の目安で、正確な測量値ではありません。

### 測定状態とプレビューの制限

JavaScriptの読み込みとクリックイベントの登録後に測定ボタンが有効になります。読み込みが失敗した場合やJavaScriptが無効の場合は、初期画面に対処方法を表示します。ボタンを押すと「測定中」、結果に応じて「測定成功」または「測定失敗」を表示します。

プレビューのiframeや配信元の `Permissions-Policy` が位置情報を禁止している場合は、アプリ側から許可を変更できません。HTTPSの独立したタブで開くか、配信設定を確認してください。位置情報の許可状態は対応ブラウザーのPermissions APIでも確認し、拒否時は設定変更を案内します。APIの無応答・許可待ちには25秒の監視タイマーで対処し、打ち切り後の遅い応答が結果を上書きしないようにしています。

### ブラウザーテスト

上記のHTTPサーバーを起動した状態で実行します。開発環境の `playwright` とChromiumが必要です（アプリ自体に依存パッケージはありません）。Chromiumが別の場所にある場合は `CHROMIUM_PATH` で指定できます。

```sh
node tests/geolocation.cjs
```

20シナリオを検証します。位置情報の正常値・エラー・無応答は模擬し、Permissions-Policyヘッダーによる実際のブラウザー制限、外部ファイル取得を遮断した場合、基準URLのないsandbox iframeでの初期化・クリック、JavaScriptの無効化も確認します。実機GPSと実際の公開プレビューの設定は、このテストの検証対象外です。


### 単一HTMLのプレビュー

`index.html` は処理・スタイルを埋め込んだ単一ファイルです。基準URLのないHTMLプレビューでも、相対パスの `app.js` や `style.css` の取得に依存しません。ソースを編集したら次を実行してHTMLとCSPハッシュを更新してください。

```sh
node scripts/build.cjs
node scripts/build.cjs --check
```

CSPは埋め込んだコードのSHA-256ハッシュを許可し、ネットワーク接続の禁止を維持します。任意のインラインスクリプトを許可する設定にはしていません。HTML末尾でイベントを登録し、完了後にボタンを有効化します。

ただし、プレビュー側がJavaScriptを除去する場合、iframeに `allow-scripts` がない場合、配信側CSPでスクリプトが禁止されている場合は、HTML側から実行を許可できません。上記テストはローカルChromiumによる再現テストであり、Codexの実際のウェブプレビューでの確認を意味しません。

### SNS第一段階：端末内デモ

- ニックネーム（1〜20文字）の登録・変更と、このブラウザー用のデモ招待コードを表示します。招待コードは認証や他端末からの友達追加には使えません。
- 「招待コードで友達を追加」から `DEMO-SORA` / `DEMO-YAMA` を入力すると、架空の友達の標高・固定の最終更新日時を表示します。任意の実際の招待コードは検索せず、実際の登録や同期は行いません。
- プロフィール・コード・サンプル友達の選択のみ `localStorage` に保存します。保存できないプレビューなどでは案内を表示し、その画面内だけで使えます。
- 共有設定は初期オフで、ページ再読み込み時にもオフに戻ります。オンにしたうえで測定後に「標高を共有」を押すと、その時点の標高と時刻を端末内の共有プレビューに反映します。オンにするだけ・再測定だけでは共有プレビューを更新しません。
- オフにすると共有プレビューを消去します。再測定中・測定失敗時は過去の測定値を新たに共有できません。標高・共有プレビューはメモリー内だけに保持し、緯度経度を扱わず、外部送信・データ同期・標高の永続保存は実装していません。

`app.js` が標高測定、`sns.js` がSNSデモです。どちらかや `style.css` を変更したら `node scripts/build.cjs` で配信用の単一 `index.html` を更新してください。

追加テスト（HTTPサーバー起動後）：

```sh
node tests/social.cjs
```

登録・変更・招待コード検証・サンプル一覧・共有の明示的な操作・オフ時消去・再読み込み・保存不可・不正な保存データ・スマホ幅・外部通信なしをブラウザーで確認します。測定値は模擬値を使用します。
